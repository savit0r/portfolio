# Portfolio Content Guide

## Identity

Primary positioning:

> Software Engineer focused on Java, Spring Boot, backend systems and
> full-stack development.

Secondary positioning can mention: - React - REST APIs - Microservices -
databases - cloud/deployment - AI-ready applications

Avoid claiming expertise where the existing portfolio does not support
it.

## Writing Rules

Use: - short sentences - concrete technical details - real numbers only
when verified - active voice - developer vocabulary without excessive
jargon

Avoid: - "passionate developer" - "coding ninja" - "rockstar
developer" - inflated performance claims - generic AI-generated
motivational statements
